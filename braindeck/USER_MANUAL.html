1. 👦 초등학생(아이용) 3초 시작 가이드 (첫째 · 둘째 키즈 모드)

초등 키즈 프로필을 선택하면 복잡한 메뉴와 어려운 통계가 자동으로 숨겨지고, 큰 글씨 · 4지선다 · 3버튼 평가 · 별 도장 10칸 중심의 단일 집중 화면으로 전환됩니다.

1단계. 오늘 공부 3초 만에 시작하기 (내 프로필과 목표 고르기)

  1. 내 이름 고르기: 화면 맨 위 프로필 선택 바에서 👦 초등 키즈 · 첫째 또는 👧 초등 키즈 · 둘째를 선택합니다. (형제·자매마다 진도와 오답, 연속 학습일이 완전히 따로 저장됩니다!)
  2. 오늘 풀 문제 수 정하기: 하루 10문제 / 15문제 / 20문제 / 30문제 중 오늘 목표를 고릅니다. (초등 저학년은 10문제, 고학년은 15문제 권장)
  3. 1-Tap 바로 시작:
  4. 🇬🇧 영어: 초3·4 필수(240) · 초5·6 완성(400) · 중등 필수(500) 중 내 단계를 고르고 [영어 시작] 클릭!
  5. 🀄 한자: 8급 기초(100) · 7급 초등(150) · 6~4급 중급(400) · 중등 한자(450) 중 내 급수를 고르고 [한자 시작] 클릭!

2단계. 초록색 코칭 배너 읽고 문제 풀기

  1. 🔤 영어 카드 (자동 발음 + 파닉스 코칭):
  2. 새 영어 카드가 나오면 원어민 발음이 자동 재생됩니다. 다시 듣고 싶으면 [🔊 발음] 버튼(단축키 R)을 누릅니다.
  3. 카드 상단 초록색 코칭 배너에 [ a _ _ _ e ] (5글자) 스펠링 블록 힌트와 파닉스 발음 규칙(Magic-e, ee/ea 장모음, bread/head 단모음 [에] 예외, -tion/-sion 등)이 함께 표시됩니다.
  4. 漢字 한자 카드 (1,728자 전수 부수·총획·활용어 코칭):
  5. 한자 카드가 나오면 초록색 코칭 배너에 漢字 조자 원리 — 글자: 校 | 부수: 木(나무 목) | 총획: 10획 | 활용 단어: 학교(學校) · 교실(教室)처럼 뜻의 뿌리(부수), 정확한 Unihan 표준 획수(예: 道 = 13획, 學 = 16획), 실생활 활용 단어가 자동 표시됩니다.
  6. 영단어가 없는 순수 한자·국어 카드에서는 오작동 방지를 위해 영어 자동 발음이 자동으로 생략됩니다.
  7. 🎯 4지선다 풀고 키즈 3버튼으로 넘기기:
  8. 4개 보기 중 정답을 누르면 다음 카드로 바로 넘어가지 않고, 같은 화면에서 정답과 해설이 먼저 펼쳐집니다.
  9. 해설을 확인한 뒤 아이 눈높이에 맞춘 3개 버튼 중 하나를 눌러 다음 카드로 넘어갑니다:
    • 😢 몰랐어요 (다시): 틀렸거나 몰랐던 카드 (오답 노트에 자동 기록되고 곧 다시 복습해요)
    • 🤔 헷갈려요 (복습): 맞혔지만 조금 헷갈렸던 카드 (짧은 간격 뒤 한 번 더 확인해요)
    • 😊 알아요! (통과): 확실히 아는 카드 (기억 주기에 맞춰 며칠 뒤 복습해요)

3단계. 별 도장 10칸 완주 축하 & 오늘 오답 다시 풀기

  1. ⭐ 별 도장 10칸: 문제를 풀 때마다 상단 별 도장(⭐⭐⭐⭐⚪⚪⚪⚪⚪⚪)이 채워집니다.
  2. 🏅🎉 오늘의 목표 완주 축하 창: 목표 문제 수를 다 채우면 축하 모달이 자동으로 열립니다.
  3. [🔥 오늘 틀린·모르는 문제만 다시 풀기]: 오늘 몰랐어요 / 헷갈려요를 눌렀던 카드만 모아서 깔끔하게 복습합니다.
  4. [➕ 오늘 목표 10문제 더 풀기]: 힘이 남을 때 오늘 목표를 +10문제 연장합니다(앱을 껐다 켜도 당일 연장된 목표가 유지되며 다음 날 자정에 원래 기본 목표로 자동 복귀합니다).
  5. [✅ 오늘 공부 기분 좋게 끝내기]: 기분 좋게 학습을 마치고 내일 연속 학습일(🔥 연속 N일째)을 이어갑니다.
  6. 📝 상단 [오늘 오답 (N)] 버튼: 학습 중 언제든 누르면 오늘 틀렸던 카드(여러 과목 덱을 오가며 틀린 카드 포함)만 즉시 모아 복습할 수 있습니다.

2. 🧑‍🎓 중고등 내신·수능 & 👨 성인·프로 5대 탭 완전 활용 가이드

상단 프로필을 🧑‍🎓 중고등 내신·수능 또는 👨 성인·프로 워크스페이스로 전환하면 전체 5개 탭(🏠 학습 · 🏫 시험·급수 · ➕ 만들기 · 🛒 스토어 · 📊 내 정보)과 4단계 정밀 평가 버튼(1·다시 / 2·어려움 / 3·알맞음 / 4·쉬움), FSRS-5 기억 지표(S 안정성 · D 난이도 · R 인출 확률)가 활성화됩니다.

① 🏠 학습 탭 — 3대 풀이 모드 & 실전 학습 도구

  • 3가지 풀이 모드 전환:
  • 4지선다 모드 (choice): 품사·시대·수식 형태가 일치하는 고난도 동형 오답 보기로 개념을 빠르게 변별합니다. (오답·모름 상태에서는 기억 왜곡 방지를 위해 1·다시만 허용하는 메타인지 평가 가드가 작동합니다.)
  • 카드 뒤집기 모드 (flip / 플래시카드 능동 인출): 앞면 질문만 보고 머릿속으로 답을 떠올린 뒤 [정답 보기](Space/Enter)를 눌러 스스로 1~4 난이도를 평가합니다.
  • 서술형 인출 모드 (typing): 정답을 직접 타이핑하여 제출하면 철자·핵심 키워드 일치도를 자동 채점합니다(오타였을 경우 [정답으로 인정] 오버라이드 지원).
  • 카드 보조 액션 바:
  • ✍️ 필기장: 한자 획순이나 영단어 철자를 손가락·애플펜슬·S펜·마우스로 직접 써 보며 외우는 드로잉 캔버스를 엽니다.
  • 힌트 (단축키 H): 정답 전체를 바로 노출하지 않고 글자 수·초성·구조 힌트를 단계별로 제시합니다. (힌트를 사용한 카드에서는 인출 강도 보정을 위해 최대 평가가 2·어려움(Hard)으로 자동 제한되며 3·알맞음 / 4·쉬움은 잠깁니다.)
  • ☆ 중요 / 오늘 숨기기(Bury) / ↩️ 되돌리기(Z) / 🔄 초기화: 중요 카드 별표 필터링, 당일 형제 카드 숨김, 직전 평가 즉시 취소(FSRS 상태 완벽 복원), 현재 덱 진도 초기화를 지원합니다.
  • [필터·도구] 및 D-Day 플래너:
  • D-Day 학습계획 (D-7 / D-14 / D-30 등): 시험일까지 남은 기간과 하루 투자 시간(분)에 맞춰 일일 신규 카드 할당량을 자동 계산합니다.
  • 전자 셀로판지 요약시트: 빨간 셀로판지로 정답을 가리고 터치해 확인하듯 전체 카드를 한눈에 훑어보는 시험 직전 요약표입니다.
  • 2단 쪽지시험지 인쇄/PDF: 학원·가정 점검용 2단 편집 시험지 및 정답지를 즉시 생성·인쇄합니다.
  • 통학 오디오 루프: 등하굣길·출퇴근길에 화면을 보지 않고 질문과 정답을 음성으로 반복 청취합니다.
  • 무오염 벼락치기(CRAM): 시험 전날 전 범위를 무한 반복해도 원본 FSRS 장기기억 스케줄(Stability)을 오염시키지 않는 샌드박스 모드입니다.

② 🏫 시험·급수 탭 — 교과서 시험범위 & 합본 덱 빌더

  • 교과서 단원·페이지 맞춤 시험범위 생성: 중·고교 주요 교과서와 출판사 단원(Lesson 1, Lesson 2 등) 및 시작~끝 페이지(예: 10p ~ 35p)를 지정해 내신 시험범위 전용 덱을 즉시 생성합니다.
  • 다과목 합본 시험 덱 (중간/기말 합본): 영어·한자·역사·과학 등 여러 시험범위를 하나의 벼락치기 합본 덱으로 묶어 교차 인출(Interleaved Practice)할 수 있습니다.

③ ➕ 만들기 탭 — 문서/사진·직접 입력·AI 자동 카드 생성

  • 📄 문서·사진 자동 추출 (doc): 강의 교안 PDF, 텍스트 파일, 노트 사진을 올리면 핵심 용어와 정의를 추출해 미리보기 목록을 만들고 원하는 카드만 골라 일괄 저장합니다.
  • ✍️ 직접 카드 추가 (manual): 앞면·뒷면을 직접 입력하며, [빈칸 {{c1::...}} 삽입](다중 Cloze c1, c2, c3 자동 분리 지원)과 [이미지 가림막(Image Occlusion)] 도형 마스킹 카드를 지원합니다.
  • 🤖 텍스트·교안 스마트 생성 (ai): 교과서 본문이나 요약 노트를 붙여넣고 난이도를 선택하면 핵심 문답 카드를 자동 생성·저장합니다.

④ 🛒 스토어 탭 — 검증된 1,000+ 문항 브레인팩 마운트

3. 📱 갤럭시 Z 폴드7 & 태블릿 대화면 적응형 레이아웃 가이드

Android 네이티브 앱(BrainDeck v1.1.0, Build 109 · 패키지 ID com.braindeck.app)은 320dp 커버 화면부터 900dp+ 펼침 화면·태블릿, 시스템 글꼴 크기(1.0x ~ 1.35x)까지 32가지 해상도 조합에 자동 반응합니다.

  • 접힌 커버 화면 (< 380dp): 한 손 엄지 조작에 최적화된 컴팩트 헤더(📖, ↩️, 🔄 초기화) 및 하단 고정 평가 버튼 배치.
  • 펼친 대화면 / 북모드 (FoldingFeature.Orientation.VERTICAL): 물리적 힌지 경계를 피해 좌측 질문·코칭 영역과 우측 보기·평가 영역을 쾌적한 가독 폭(max 720dp)으로 배치.
  • 절곡 테이블탑 모드 (HALF_OPENED + HORIZONTAL): 책상 위에 반쯤 접어 세워 두면 상단 화면에는 플래시카드 문제·해설을, 하단 화면에는 터치 조작 버튼을 분리 배치합니다.

자주 묻는 질문 (FAQ)

  1. Q. 상단 탭 메뉴(시험·급수, 스토어, 만들기)가 보이지 않아요!
  2. 현재 프로필이 👦/👧 초등 키즈로 선택되어 있으면 아이가 다른 메뉴로 이탈하지 않도록 상단 탭을 자동으로 숨깁니다. 상단 프로필을 🧑‍🎓 중고등 또는 👨 성인·프로로 바꾸면 모든 탭과 고급 도구가 즉시 나타납니다.
  3. Q. 영어 발음 소리가 안 나거나 한자 카드에서 [🔊 발음] 버튼이 비활성화돼요.
  4. 상단 [🔊 자동발음 ON] 켜짐 여부와 기기 미디어 볼륨(iOS 매너모드 해제)을 확인해 주세요. 순수 한자·국어 카드는 엉뚱한 영어 기계음 방지를 위해 영어 자동 발음을 자동으로 건너뜁니다.
  5. Q. 연속 학습일(🔥 연속 N일)과 오늘 목표는 언제 초기화되나요?
  6. 기기의 로컬 자정(밤 12시, 00:00) 기준입니다. 전날 기본 목표 이상을 완주했다면 다음 날 접속 시 연속 학습일이 자동으로 +1일 이어집니다.
  7. Q. 이전 테스트 앱(com.ankistudio.app)에서 새 정식 패키지(com.braindeck.app, Build 109+)로 학습 기록을 옮기려면?
  8. 패키지 식별자가 상표권 클린룸 기준인 com.braindeck.app으로 독립 분리되어 두 앱이 기기에 나란히 설치될 수 있습니다. 구버전 앱의 [📊 내 정보] ➔ [.apkg 내보내기](또는 [JSON 백업])로 학습 금고를 저장한 뒤, 새 BrainDeck 앱에서 가져오기(Import)를 실행하면 복습 스케줄과 카드가 100% 그대로 이전됩니다.
  9. Q. 오픈소스 라이선스 및 데이터·상표권 비제휴 고지문은 어디서 확인하나요?
  10. 웹앱 하단·스토어 탭 또는 Android 앱 내 [오픈소스 라이선스] 버튼을 누르면 인터넷 연결이 없는 오프라인 상태에서도 THIRD_PARTY_NOTICES(CMUdict BSD-2-Clause, Unicode Unihan Unicode License v3, Apache-2.0, MIT, Google ML Kit 고지 및 공유저작물 출처 388행 전문 + SHA-256 무결성 해시)를 즉시 열람할 수 있습니다.
